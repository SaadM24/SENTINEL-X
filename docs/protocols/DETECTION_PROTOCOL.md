# Tabular protocol, frozen before scoring

Only f_* columns enter models. Use supplied disjoint train/cal/test partitions. Training fits median imputation, clipping to train-derived 0.5/99.5 percentiles and scaling. Retain constants. A separate calibration partition fits every map and sets confidence quantiles. No hyperparameter search. Fit logistic regression, random forest, histogram gradient boosting, benign-only isolation forest, MLP classifier, benign-only bottleneck autoencoder, and a fixed-centre RBF neural classifier. The last tests local similarity as a nonlinear inductive bias. Anomaly scores become training benign empirical percentiles; these uncalibrated scores have no probabilistic interpretation. Use balanced weights on logistic, forest, and RBF head. Use fixed seeds and retain all results. Primary operating point is logistic + Platt regardless of rankings.

Evaluate raw, temperature, Platt and isotonic maps with the same held-out events. Decision threshold 0.5 inclusive. ECE uses ten equal-width probability bins, left inclusive with 1 assigned to last. Report both average precision and trapezoidal PR area. Confidence is max(p,1-p). Target review fractions are 0%, 5%, 10%, 20%, 50%; set confidence threshold to the calibration quantile, retain all ties. Actual workload can differ from target. Report error fraction among accepted decisions and realized review count. Reliability uses binary event outcome; per-category analyses report errors and denominators.

Controlled shift only: replace the first f_* feature in source column order with its training median for every test row; compare logistic Platt on identical records. This sensor outage measures sensitivity to a missing measurement. External validity requires independent collection. Estimate global noncausal importance by permuting each feature once using a fixed seed, measuring drop in held-out average precision for primary model. Explanations and test scores are descriptive and never used to revise the model. Wilson intervals on primary decision error assume independent records and understate dependence where present. Measure warmed, batched classifier score generation on preprocessed arrays; resource/time values describe this host only. Release registry distinguishes fixture from benchmark via data manifest. No scan, traffic capture, live inference endpoint, or incident action.
