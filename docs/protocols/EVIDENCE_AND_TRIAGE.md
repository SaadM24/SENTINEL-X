# Evidence and triage protocol

## Investigation question

Can an analyst verify exactly which alert fields a report used, and does same-session retrieval recover the available chronology? Compare three deterministic conditions per case. The full method retrieves an anchor and records sharing its nonempty session ID. The anchor-only condition disables correlation. A citation-stripping ablation preserves the full text and removes its links, isolating traceability from factual accuracy. It is an ablation, not evidence about the behaviour of an actual free-form LLM.

Cases and expected answers are specified in separate JSON files before execution. They are synthetic unit-level investigation scenarios authored by the implementer, with no independent reviewers. They include unknown IDs, incomplete alerts, ties, invalid/missing dates, unrelated records with a similar session, scores below threshold, and text resembling an instruction. Exclude labels and outcome-bearing categories from all model evidence. Treat supplied score as a model output only. Do not translate scores into attack outcomes. Refuse ambiguous duplicate record IDs at ingest. A report may state that the scope is insufficient without inventing a chronology.

For each output observation, match its (field, value) pair to the answer key, check each cited event field directly, and check that every reported claim has at least one supporting citation. Report the fraction of true field values, the fraction of supported citations among citations provided, and the fraction of claims lacking at least one valid citation. These are different measurements. Undefined rates are null. Evidence sufficiency requires all expected facts to be cited and all adjudicated related IDs recovered for a reportable case. Abstention correctness compares expected and actual status across every case. Timeline exact match requires the ordered IDs to match the key, with ties broken by event ID; empty timelines count. Investigation completeness measures related-ID recall on reportable cases. Output one CSV review row per case-condition pair. Two independent human assessors should inspect records, blind system names via review IDs, mark yes/no/unclear and document disagreements. Exclude training or developer feedback from independent review.

## Integrated experiment

Fixed model: Platt-scaled logistic regression (the upstream experiment also exports raw fitted probabilities). Treat test predictions as a read-only file. Fix thresholds before evaluation. Compare five policies: accept all raw decisions; accept all calibrated decisions; escalate calibrated decisions with confidence <0.70, <0.85 or <0.95. A score >=0.5 predicts positive. Confidence is max(p,1-p). Record errors remaining among automatic decisions, escalated errors, escalation count, coverage, risk and unnecessary escalations (would-have-been correct). A hypothetical perfect reviewer can correct at most the count of escalated errors. No human time, reviewer effectiveness or operational saving is measured. For the 0.85 policy, compare a scored-alert display with a cited report of the same model and probability. Evaluate traceability from stored records; the report cannot improve classification decisions by itself. No traffic evidence or attack causation is inferred from flow identifiers. Persist all decisions and cited reports for reproduction.

Results are descriptive finite-sample measurements. The main investigation comparison measures clerical verification and retrieval within a controlled schema. No ground truth on human usefulness is available.

### Follow-up evaluation on benchmark records

After inspecting aggregate triage results, specify an exploratory packet for later human review. Sample up to five correct negatives, five false positives, five false negatives and five correct positives by smallest SHA-256 of the event ID within each stratum. Use the frozen 0.5 decision boundary on the Platt score. This case-control set cannot estimate any population error rate. Show only the pseudonymous record ID, measured flow values, model output, binary decision and escalation policy to the reviewer. Keep labels in a coordinator-only key. Provide one additional deterministic reference control: replace the citation candidate with the next packet event, cyclically. Count exact field matches with and without an explicit anchor-ID equality check. Do not export mismatched citations as report findings. Repeated values can match on the wrong event; the control measures this failure mode, not real-world explanation quality.
