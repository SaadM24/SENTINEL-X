# Experiment 4 · Frozen before evaluation

Question H4 asks whether adjacent system-call dependencies improve trace anomaly ranking over token frequencies. Each ADFA-LD file is one already ordered trace. Never concatenate files or reorder tokens. No wall-clock or host chronology is available. Positive means a file from an attack scenario, which does not prove every process action was malicious. Features are integer syscall IDs only. File names and scenario labels are metadata.

Use the pinned, checksum-verified ADFA-LD ZIP described by the runner. Training_Data_Master supplies benign fitting and calibration traces. Sort unique training token-stream digests by SHA-256; hold every fifth trace for calibration; fit on the remainder. Use the published Validation_Data_Master as held-out benign and Attack_Data_Master as held-out positive. Exclude duplicate normalized streams within splits and held-out copies of training streams. Discard held-out stream groups with conflicting benign/attack labels. Keep the alphabet and all transition counts training-only. Do not select parameters or thresholds using test data.

Compare a fixed unigram with a first-order Markov model, each using additive 0.5 smoothing, start and end boundaries, and an unknown token. Score by mean negative natural log probability over the trace and end marker. Use the calibration benign-score 95th percentile (higher quantile, strict greater-than alarm), independently for each model. Primary endpoint is test average precision. Report ROC-AUC, threshold confusion, FPR, recall, precision, macro-F1, family sensitivity and trace-level paired scores. No formal independence-based confidence interval: attack files within one scenario can be correlated; benign episode IDs are unavailable. Training transition probabilities and most surprising token transitions are descriptive.

The fixture uses generated traces, with anomalies made by changing order while preserving the token multiset. This tests sensitivity to order by construction. Its scores cannot establish transfer to security telemetry. This experiment is a two-model ablation, not an estimate of model fusion or benefit to analysts.
