# Exploratory fusion analysis · Specification before its first execution

The primary v0.3 comparison has already used this corpus. This follow-up responds to the exploratory question of combining a supervised independent-event baseline with a genuine order score. It is a new split of a previously inspected corpus; findings require new external confirmation.

1. Fit the fixed alpha=0.5 Markov density on unique benign traces in the original Training_Data_Master only. Its inputs are disjoint from every supervised partition.
2. Use remaining unique Validation_Data_Master benign traces and Attack_Data_Master positives. Remove every overlap with density training and every conflicting-label digest. For exact copies in multiple attack scenario directories, drop the entire digest group; for within-scenario duplicates retain one. Do not use trace filename or scenario as a predictor.
3. Within each attack family sort scenario directories by salted SHA-256 and place indices 0 mod 5 in test, 1 mod 5 in calibration, others in supervised fitting. For benign traces use the identical rule on sorted salted content identifiers. Allow correlation between benign traces because recording sessions are unidentified. This experiment tests new recorded scenarios of known families only.
4. Model A: empirical token frequencies, with a single unknown bucket, L2 logistic regression (C=1, fit intercept, no class reweighting) after StandardScaler. Model B: add the length-normalized Markov surprise, all other settings identical. Fit the token vocabulary on the independent density-training pool. Fit StandardScaler on supervised fitting only. Fit sigmoid calibration only on calibration-set decision scores. Threshold calibrated probability at 0.5.
5. Compare test AP, ROC-AUC, raw/calibrated Brier and ECE (ten equal width bins), confusion, error. Fix a 20% review target via calibration entropy ranking (maximum class probability bottom quintile, ties included). Report held-out realized coverage and accepted error. Also report accepted error at exactly floor(0.20*N) reviews by ranked confidence on an offline batch, using salted digest tie-breaks. This batch comparison assumes an available queue, with no test labels used in the queue.
6. Save split digests and scenario groups, paired scores, calibrated model parameters, runtimes, schema and measured metrics. Do not claim measured analyst time or external transfer.
