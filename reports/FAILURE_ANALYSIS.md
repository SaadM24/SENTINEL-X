# Failure analysis

1. **Transfer failure.** At a frozen 0.5 threshold on native NF-v2, a source-trained logistic model falsely flagged 57/1,214 source benign vectors and 6,456/9,797 external benign vectors. External recall increased, but the ranking also deteriorated (ROC-AUC 0.298). Changing the threshold after seeing the target labels would answer a different question. The data cannot isolate the collector, background traffic or attack mix as a causal explanation.
2. **Operational false alarms.** The raw forest, which had the highest full native macro-F1 of the fixed models, still flagged 7,755/30,049 benign vectors. Many are removed or downweighted when projected-vector duplication is handled differently. The paper reports per-1,000 benign *eligible vectors*.
3. **Representational leakage.** Clipping and conversion created 62 test matches to an earlier transformed vector. Excluding them barely changed the primary logistic average precision. Distinct vectors may still belong to dependent flows.
4. **Non-convergence and calibration.** The MLP and reconstruction model reached the fixed epoch budget. Their recorded warnings are retained. Platt scaling worsened forest Brier. One global calibration method did not improve every family.
5. **Weak evidence.** Session retrieval cannot build an incident history for independent UNSW rows. Nine fact fields in synthetic cases are too few for broad conclusions. A correct reference to a score is evidence about the model's output only.
6. **Environment.** The default system Chromium initially could not open its singleton socket. The browser log is preserved; a headless-shell run completed navigation, charts and feedback. Linux smoke and research paths ran. Actual Windows execution, CUDA training and live language-model integration remain unmeasured.
