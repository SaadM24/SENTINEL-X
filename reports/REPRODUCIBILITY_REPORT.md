# Reproducibility and integrity

**Executed environments.** The primary CPU benchmark used Linux, Python 3.12.14 and scikit-learn 1.8.0. A fresh Linux Python 3.11.18 environment installed the pinned dependencies and passed the complete smoke workflow. Windows 3.11 x64 wheel resolution and syntax parsing of all five PowerShell wrappers succeeded. The release contains no native Windows runtime result or GPU benchmark.

**Automated checks.** The release suite passed 49 tests. The full native detector replay, three bounded seeds and synthetic smoke replay checked 140 model/calibrator combinations. Checks include hash, confusion, Brier, primary scores and workload arithmetic. Independently implemented sequence verification recomputed AP, confusion and fusion Brier and accepted-error values from trace-level files. Repeated sequence runs yielded byte-identical score tables, model parameters and partitions. Browser checks used desktop/mobile viewport widths and a temporary review database. A fresh bounded real workflow and resume each completed twelve stages. Exact invocations and outputs are in results/v10/workflow_qa, results/v10/release_qa, results/workflow, results/v05 and reports/sequence.

**Interpretation of status.** Implemented means code exists. Tested means an automated or browser check ran to completion. Executed means real outputs were written. Internally checked metrics are those recomputed against the described protocol. No result has undergone external scientific replication or independent human adjudication. A stage passing its software checks does not qualify its scientific conclusion as independently validated.

**Artifacts and integrity.** The release manifest maps each packaged file to a hash and indexes component-level results. Raw third-party archives, virtual environments and transient caches are omitted; their source identities, bytes and retrieval scripts are preserved. Packaged native cohorts can be inspected offline. Sequence and NetFlow model outputs are included; rebuilding their inputs needs the named archives. Run `python scripts/verify_results.py` from the extracted repository for archive hashes and flow checks, then `python scripts/verify_sequence.py`. Check native cross-domain confidence intervals in results/external/nf-v2-audit.json.

**Versioning.** The six version manifests index logical releases of one integrated source tree. Independent modules were developed concurrently; these manifests are not six historical Git checkout snapshots. Stored evidence, schemas and settings for each release remain individually inspectable. The registry carries run IDs, parameters, platform and links to producer-specific metadata and results. A source hash identifies this build without an external Git repository.

**Remaining reproducibility limits.** A native Windows launch, optional CUDA backend, live local LLM inference and independent reviewer scores remain outstanding. External URLs can change. Pin checks reject unexpected benchmark bytes. Host-dependent timing and stochastic optimization can vary across binaries. Numerical conclusions concern the recorded splits and implementations.
